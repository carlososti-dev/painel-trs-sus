# Diálise no SUS – Painel TRS

Painel sobre terapia renal substitutiva (diálise) no SUS, a partir de dados públicos do DATASUS
(APAC de Tratamento Dialítico – SIA/SUS, CNES, CNESNet, Base territorial), ago/2024 a jul/2026.

- **Painel:** `index.html` (Brasil e por estado; abas de visão geral, estabelecimentos, acesso,
  qualidade, transplante, planejamento e metodologia).
- **Chat "Pergunte aos dados":** `chat.html`. Precisa de servidor com a chave da API da Anthropic
  (`api/claude.js` na Vercel); no GitHub Pages ele fica indisponível. Veja `LEIAME.md`.
- **Dados:** `dados/` — somente tabelas agregadas; nenhuma informação individual de pacientes.
